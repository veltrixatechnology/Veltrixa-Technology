## Tech stack

This marketing site is built with:

- **Next.js 14** (App Router) + **TypeScript**
- **Tailwind CSS** for styling
- **React Three Fiber** / Three.js for the hero 3D monogram
- **Framer Motion** & **GSAP** for motion
- **React Hook Form** + **Zod** for contact / booking forms
- **Resend** for lead email delivery (optional env key)
